## ⚡ Local Processing Pipeline

1. **Speech-to-Text (STT):** Transcribes local `.wav` files from `audio_input/` using quantized Whisper (`ggml-tiny-q8_0.bin`).
2. **Neural Machine Translation (NMT):** Translates Spanish text to English in-memory via Argos Translate.
3. **Text-to-Speech (TTS):** Synthesizes translated text into English speech using Piper ONNX (`Voices/`) and outputs to `audio_output/`.

## 🛠️ Setup & Installation Instructions

### 1. Clone the Project Repository

```bash
git clone <repository-url>
cd Edge-and-Optimization-on-Wearable-AI-Audio-Translator

```

### 2. Create & Activate Virtual Environment

**On Linux / Raspberry Pi / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate

```

**On Windows (PowerShell):**

```bash
python -m venv venv
.\venv\Scripts\Activate.ps1

```

### 3. Install Dependencies

```bash
pip install --upgrade pip
pip install argostranslate

```

### 4. Model Weights & Binaries Setup

Ensure your local environment contains the necessary offline binaries in their respective paths:

* **Argos Language Pack:** Place `translate-es_en-1_9.argosmodel` in the root directory.
* **Whisper Quantized Model:** Place `ggml-tiny-q8_0.bin` in the root directory.
* **Piper TTS Files:** Place `en_US-ryan-low.onnx` and `en_US-ryan-low.onnx.json` inside the `Voices/` directory.
